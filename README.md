# Храмы Мостовского района

Школьный проект: сайт-маршрут по 12 православным храмам Мостовского района
(Гродненская область, Беларусь). Маршрут чисто православный
(DG8, 2026-09-02: католические костёлы убраны из маршрута).

## Стек
Чистые HTML/CSS/JS, без сборщиков и внешних CDN. Данные — в `js/data.js`.
Роутинг — `#/slug`. Размещение — GitHub Pages.

## Структура
```
├── index.html          ← главная: схема района, маршрут, список остановок
├── about.html          ← «О проекте»
├── css/style.css       ← дизайн-токены и стили (единый источник)
├── js/data.js          ← ВСЕ данные о храмах и маршруте
├── js/app.js           ← роутинг и рендер страниц храма
├── js/map.js           ← SVG-схема района и линия маршрута
├── img/photos/         ← фото храмов (атрибуция в data.js → photoCredit)
└── RESEARCH.md         ← ledger исследований и решений
```

## Как править контент после сдачи
1. Открыть `js/data.js` в веб-интерфейсе GitHub (иконка карандаша).
2. Изменить текст/координаты/фото нужного храма.
3. Commit changes → сайт обновится через 1–2 минуты. Инструменты не нужны.
