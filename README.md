# Дорогами духовности — маршрут по храмам Мостовского района

Школьный проект по истории: сайт-маршрут по трём действующим православным церквям
Мостовского района (Гродненская область, Беларусь) — **Гудевичи → Лунно → Дубно**.
Это Блок 1 «Дорогами духовности» конкурса «Гродненщина православная»
(туристско-краеведческий), поэтому сайт состоит ровно из шести его обязательных
элементов: нитка маршрута, карта-схема, описание, логистика, справочная информация,
фотоотчёт.

## Стек
Чистые HTML/CSS/JS, без сборщиков и внешних CDN. Данные — в `js/data.js`.
Роутинг — `#/slug`. Размещение — GitHub Pages.

## Структура
```
├── index.html          ← приложение: шесть отделов + страницы храмов
├── about.html          ← «О проекте», задание и источники
├── css/style.css       ← дизайн-токены и стили (единый источник)
├── js/data.js          ← ВСЕ данные о храмах, маршруте и питании
├── js/church-icon.js   ← единый условный знак: иконка церкви (SVG)
├── js/map-geometry.js  ← контур района, река, дороги, проекция координат
├── js/map.js           ← отрисовка схемы: иконки, нитка маршрута, легенда
├── js/views.js         ← отрисовка отделов и страниц храмов
├── js/router.js        ← разбор адреса и порядок маршрута
├── js/app.js           ← связка адресов и отделов
├── img/photos/         ← фото храмов (атрибуция в data.js → photoCredit)
│   └── visit/          ← сюда лягут личные фотоотчётные снимки
├── tests/              ← контракты без фреймворка (см. tests/README.md)
└── MASTER-PLAN.md      ← план, решения (DG) и что автор закрывает сам
```

## Проверка
```bash
node tests/contract.js
node tests/content-completeness.js
```

## Как править контент после сдачи
1. Открыть нужный файл в веб-интерфейсе GitHub (иконка карандаша).
2. Текст, координаты, контакты — в `js/data.js`; стили — в `css/style.css`.
3. Если правился `css/style.css` или файл из `js/`, поднять номер версии у этого
   файла в `index.html` и `about.html` (`style.css?v=21` → `?v=22`): иначе браузер
   посетителя отдаст старую копию из кэша.
4. Commit changes → сайт обновится через 1–2 минуты. Инструменты не нужны.
